# Routing & Navigation Architecture

- File-based routes under `src/routes/`:
  - `/` (`src/routes/index.tsx`): Main single-page portfolio with section anchors (`#about`, `#skills`, `#projects`, `#contact`).
  - `/privacy` (`src/routes/privacy.tsx`): Privacy policy document.
  - `/terms` (`src/routes/terms.tsx`): Terms of service document.
  - `/cookies` (`src/routes/cookies.tsx`): Cookie policy document.
  - `/sitemap.xml` (`src/routes/sitemap[.]xml.ts`): XML sitemap endpoint.

# User Stories

- **US-01**: As a recruiter, I want to download Fahaman's CV immediately from the hero section so that I can share it with hiring managers.
- **US-02**: As an engineering manager, I want to filter and inspect verified cloud badges so that I can confirm practical cloud and AI competence.
- **US-03**: As a potential client, I want to submit an inquiry through a contact form and receive instant delivery confirmation so that I know my message went through.
- **US-04**: As a visitor on a mobile phone, I want an uncluttered navigation menu and touch-optimized buttons so that I can browse effortlessly without horizontal overflow.
- **US-05**: As a privacy-conscious visitor, I want clear access to privacy and cookie policies so that I know how my inquiry data and preferences are handled.
- **US-06**: As an accessibility user using a keyboard, I want to cycle through profile photos in the lightbox using Arrow keys and close with Escape.

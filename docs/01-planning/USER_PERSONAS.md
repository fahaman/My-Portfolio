# User Personas

## Persona 1: Tech Recruiter (Sarah Jenkins)

- **Role**: Senior Technical Talent Acquisition at a high-growth SaaS startup.
- **Goal**: Quickly assess Mohammed's stack (React, TypeScript, Node.js, AI/LLMs), review verified credentials, and download his CV.
- **Pain Points**: Lengthy walls of text, unverified claims, broken resume download links, and sluggish mobile sites.
- **Key Flow**: Lands on Hero -> Clicks "Resume" -> Skims "Skills" and "Certifications" -> Uses "Contact" to message.

## Persona 2: Engineering Manager (David Chen)

- **Role**: Lead Architect hiring full-stack engineers with AI familiarity.
- **Goal**: Inspect code quality, evaluate architectural choices on showcased projects, and test UI responsiveness.
- **Pain Points**: Generic portfolios with placeholder projects and no real backend or cloud understanding.
- **Key Flow**: Reviews "Selected Work" -> Inspects GitHub links -> Observes Scaler RAG pipeline and Google Cloud skill badges.

## Persona 3: Client / Startup Founder (Zoya Patel)

- **Role**: Founder looking for an engineer to build an AI-powered MVP.
- **Goal**: Review past client projects (LearnChart, HelpHive, Ellexo) and initiate a direct project discussion.
- **Key Flow**: Reviews "Work" -> Clicks "Discuss Project" -> Submits scope via Contact form.

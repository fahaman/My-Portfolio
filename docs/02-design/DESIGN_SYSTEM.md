# Design System Tokens

## Colors
- **Background (Dark)**: `#0B0F19` / `hsl(222, 47%, 7%)`
- **Background (Light)**: `#F8FAFC` / `hsl(210, 40%, 98%)`
- **Surface / Card**: `rgba(255, 255, 255, 0.03)` with border `rgba(255, 255, 255, 0.08)`
- **Primary Accent**: Gold/Amber `hsl(43, 96%, 56%)`
- **Secondary Accent**: Electric Cyan `hsl(192, 95%, 50%)`
- **Muted Text**: `hsl(215, 20%, 65%)`
- **Destructive**: `hsl(0, 84%, 60%)`

## Typography
- **Display Font**: Outfit / System sans-serif for headings (weights: 600, 700, 800).
- **Body Font**: Inter / System sans-serif for content (weights: 400, 500).
- **Mono Font**: JetBrains Mono / SFMono-Regular for tech tags and dates.

## Border Radius Hierarchy
- **Buttons & Action Controls**: `rounded-xl` (12px)
- **Content Cards**: `rounded-2xl` (16px) to `rounded-3xl` (24px)
- **Avatars & Badges**: Circular `rounded-full` reserved strictly for avatars and indicator dots.

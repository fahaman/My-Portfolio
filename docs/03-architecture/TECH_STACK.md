# Technology Stack

| Layer | Technology | Version | Rationale |
|---|---|---|---|
| Runtime / UI | React | 19.2.0 | Modern concurrent features, transitions, and component ergonomics |
| Router & SSR | TanStack Router / Start | 1.168.x | Type-safe file routing with SSR/SSG support |
| Build Tool | Vite | 8.x | Sub-second HMR and optimized production bundling |
| Styling | Tailwind CSS | 4.2.x | High-performance CSS compilation without runtime overhead |
| UI Primitives | Radix UI | Latest | Accessible, unstyled primitives (Dialog, Dropdown, Accordion) |
| Animations | Framer Motion | 12.x | Declarative scroll and entrance transitions |
| Icons | Lucide React | Latest | Consistent, lightweight SVG iconography |
| Contact API | EmailJS | 4.4.x | Direct, authenticated email dispatch without server maintenance |
| Language | TypeScript | 5.8.x | Strict type safety and autocompletion across routes |

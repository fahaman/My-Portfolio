# AI Coding Agent Instructions for Mohammed Fahaman's Portfolio

This project is a modern developer portfolio web application built with React 19, TanStack Start / TanStack Router, TypeScript, Vite, and Tailwind CSS.

## Architecture & Code Conventions

1. **Routing**: Uses TanStack Router file-based routing located in `src/routes/`.
   - Any new page must export `Route = createFileRoute("/...")({ ... })`.
   - `src/routeTree.gen.ts` is auto-generated by the TanStack Router plugin during build or dev. Do not edit `routeTree.gen.ts` manually.
2. **Component Separation**:
   - Keep UI components focused and modular under `src/components/` and `src/routes/`.
   - Isolate side-effects, API calls, and email integrations in `src/lib/`.
3. **Design Guidelines**:
   - **No Purple Gradients**: Use intentional palettes (gold, cyan, amber, slate).
   - **No Pill-Shaped Buttons**: Interactive buttons must use modern geometric borders (`rounded-xl` / `rounded-lg`).
   - **No Emojis as Interface Icons**: Always use SVG icons from `lucide-react`.
   - **Authentic Assets Only**: No fake testimonials, fabricated customer counters, or placeholder metrics.
4. **Accessibility (WCAG 2.2 AA)**:
   - Ensure all images have meaningful `alt` text.
   - All interactive controls must have accessible labels and keyboard focus indicators.
   - Maintain color contrast ratios of at least 4.5:1 for normal text and 3:1 for large text.
5. **Security & Privacy**:
   - Never commit sensitive API tokens or private keys to git or `.env.example`.
   - Keep legal documentation (`/privacy`, `/terms`, `/cookies`) synchronized with actual application data flows.
